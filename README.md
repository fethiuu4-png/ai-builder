# 🧠 عقل برو - منصة بناء وتدريب نماذج الذكاء الاصطناعي

موقع PHP + MySQL لبناء وتدريب واختبار نماذج الذكاء الاصطناعي. يدعم رفع بياناتك الخاصة بصيغة CSV و JSON.

## 📦 المتطلبات

- **PHP 7.4** أو أحدث (مع إضافة PDO MySQL)
- **MySQL 5.7** أو أحدث (أو MariaDB 10.3+)
- خادم ويب مثل Apache أو Nginx
- أو استخدم **XAMPP / WAMP / MAMP / LAMP** على جهازك

## 🚀 التثبيت السريع (XAMPP مثالاً)

### 1️⃣ انسخ المشروع
انسخ مجلد `ai-builder-php` إلى مجلد الخادم:
```
# XAMPP على Windows:
C:\xampp\htdocs\ai-builder-php

# WAMP على Windows:
C:\wamp64\www\ai-builder-php

# Linux (Apache):
/var/www/html/ai-builder-php
```

### 2️⃣ أنشئ قاعدة البيانات
افتح **phpMyAdmin** (عادةً على http://localhost/phpmyadmin) ثم:
1. اضغط على تبويب **«استيراد / Import»**
2. اختر ملف `schema.sql` من مجلد المشروع
3. اضغط **«تنفيذ / Go»**

أو عبر سطر الأوامر:
```bash
mysql -u root -p < schema.sql
```

### 3️⃣ عدّل إعدادات الاتصال (إذا لزم)
افتح `config/config.php` وعدّل القيم التالية إن لزم:
```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'aqlpro');
define('DB_USER', 'root');      // اسم مستخدم MySQL
define('DB_PASS', '');          // كلمة المرور (فارغة افتراضياً على XAMPP)
```

### 4️⃣ شغّل الموقع
افتح المتصفح على:
```
http://localhost/ai-builder-php/
```

## 🎯 كيفية الاستخدام

### 1. صمّم النموذج (تبويب «المُصمّم»)
- اختر نوع المعمارية (MLP، CNN، RNN، Transformer)
- أضف طبقات عصبية (Dense، Conv2D، LSTM، Attention، Dropout...)
- اضبط عدد الخلايا ودوال التفعيل
- اضغط «حفظ النموذج»

### 2. ارفع بياناتك (تبويب «البيانات»)
- **لصق يدوي:** الصق بيانات CSV أو JSON
- **رفع ملف:** ارفع ملف CSV / JSON / TXT من جهازك (حتى 2 ميجا)
- أو استخدم «مثال CSV» / «مثال JSON» للبيانات التجريبية
- اختر عمود المدخلات وعمود التسمية (اختياري)
- اضغط «رفع البيانات»

### 3. درّب النموذج (تبويب «التدريب»)
- اختر مجموعة البيانات (جاهزة أو مخصّصة)
- اضبط الهايبربارامترات:
  - عدد الحقب (Epochs): 15-30
  - معدّل التعلّم (Learning Rate): 0.001
  - حجم الدفعة (Batch Size): 32
  - المُحسِّن: Adam (الأفضل للبدء)
- اضغط «ابدأ التدريب» وراقب المنحنيات

### 4. اختبر النموذج (تبويب «الاختبار»)
- محادثة شات مباشرة مع النموذج
- جرّب الأمثلة الجاهزة أو اسأل أسئلة مفتوحة

## 🛡️ الأمان

- جميع استعلامات قاعدة البيانات تستخدم **PDO مع Prepared Statements** (حماية من SQL Injection)
- تنظيف المدخلات عبر `htmlspecialchars`
- للإنتاج: ضع `display_errors = '0'` في `config/config.php`

## 🔧 التخصيص

### تغيير الألوان
عدّل المتغيرات في `assets/css/style.css`:
```css
:root {
    --primary: oklch(0.72 0.20 290);   /* اللون الرئيسي */
    --accent: oklch(0.65 0.20 165);    /* اللون الثانوي */
}
```

### إضافة مجموعة بيانات جاهزة جديدة
أضفها في `index.php` ضمن قائمة `<select>` وفي `assets/js/app.js` ضمن `DATASET_INFO`.

## ❓ استكشاف الأخطاء

### المشكلة: «فشل الاتصال بقاعدة البيانات»
- تأكد من تشغيل MySQL
- تحقق من `DB_USER` و`DB_PASS` في `config/config.php`
- تأكد من استيراد `schema.sql` بنجاح

### المشكلة: صفحة فارغة
- فعّل عرض الأخطاء في `config/config.php` (افتراضياً مفعّل)
- تحقق من سجل أخطاء Apache

### المشكلة: الأحرف العربية تظهر بعلامات استفهام
- تأكد من ترميز قاعدة البيانات `utf8mb4` (موجود في `schema.sql`)
- تحقق من إعدادات MySQL في `config.php`
